# Quiet workspace

English | [中文](README.zh.md)

This optional appearance plugin gives the native sidebar, conversation header, and upper-right controls a neutral palette, system typography, consistent spacing, and visible keyboard focus. It follows the existing light/dark theme selection and respects reduced motion. Code retains monospace typography. It does not change conversations, credentials, model selection, or tools.

The PureGamma installer enables this plugin and stops enabling the earlier pixel-font and blue-bubble bundles. Their dependencies and settings remain available for manual re-enabling. Disable this plugin in the plugin manager to restore the native appearance. Capability navigation comes from [plugin rail](../dsh-plugin-rail/README.md).
