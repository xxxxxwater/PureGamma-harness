# PureGamma 专业提示词

[English](README.md) | 中文

在 Harness 会话输入框增加一个无彩色的线条 SVG 图标。点击后，插件使用本机已登录的 Codex CLI 把当前草稿改写得更完整、明确、专业；结果只替换草稿，不会自动发送。再次点击可撤回，也可先编辑结果再发送。

插件保留原意和限制，不编造事实，并按任务复杂度决定结构。它使用经过 Harness 鉴权的本地接口，在空白、只读的临时工作目录中运行一次不保存会话的 Codex CLI。插件自身不把提示词写入文件。调用会占用当前 ChatGPT 账号的 Codex 额度。如果增强期间草稿被编辑，结果不会覆盖新内容。

需要本机 Codex CLI 已登录。若 `codex` 不在常见路径，可设置 `PG_PROMPT_PRO_CODEX_PATH`。服务端最多同时处理两项增强，每项草稿最多 12,000 字符。
