# Plugin capability navigation

English | [中文](README.zh.md)

Plugin navigation lives inside the native sidebar. Up to four pinned shortcuts show an icon and label; plugins already represented by a native sidebar page are omitted. Entries come from installed plugins: dedicated pages open directly, and other entries open plugin details. Collapsing the sidebar hides these shortcuts and leaves the conversation's upper-right tools menu available.

Hovering or focusing an entry shows its capability name, package name, and version. More plugins, the upper-right tools button, and right-clicking an entry open the same searchable list with pin/unpin controls. Escape closes the menu and restores focus to its trigger. Pin choices remain stored in this desktop client; entries beyond the four visible shortcuts remain in the menu. Disable this optional plugin to restore the native layout.
